# weather_app

A comprehensive weather intelligence platform built with the MERN stack.

## Features
- Real-time weather data and forecasts
- Live radar map with temperature, precipitation, wind, and cloud layers
- AI-powered weather assistant (Gemini)
- Health center with AQI, UV index, and pollen data
- Weather journal to track mood and activities based on weather
- Community weather reports
- Astronomy dashboard with sun and moon data
- Admin dashboard for user and content management

## Tech Stack
- Frontend: React, Tailwind CSS, Vite, Leaflet
- Backend: Node.js, Express.js
- Database: MongoDB
- APIs: OpenWeatherMap, Google Gemini, Cloudinary
